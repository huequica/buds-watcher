# INZONE Buds Monitor (v0.1 スケルトン)

Sony INZONE Buds の左右イヤホンの切断を検知し、OS標準の通知を使わずに
常時最前面のオーバーレイでプッシュ通知するための常駐アプリです。

## 現状でできること

- システムトレイに常駐し、右クリックで以下を選べる
  - 「アプリケーション画面を開く」
  - 「テスト通知: 左/右を切断・再接続」(動作確認用)
  - 「アプリを終了する」
- 左右の切断を検知すると、画面右上に自前のオーバーレイ通知が出る(OS標準通知は不使用)
- トレイアイコンの色でL/Rの状態を表示(緑=OK / 赤=切断)

**まだ実装していないこと**: 実際のUSBレシーバーからの左右切断検知そのものです。
これは Sony 独自のプロトコルで、公開されている仕様がないため、実機でのUSBパケット
キャプチャが必要です(下記「フェーズ2: 実プロトコルの組み込み」を参照)。
`device.py` の `DeviceMonitor._poll()` に実装を追加するだけで、UI側は変更なしで
動くように設計してあります。

## セットアップ

```bash
python3 -m venv venv
source venv/bin/activate   # Windowsは venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
```

### GNOMEを使っている場合の注意

GNOMEは標準でシステムトレイ機能を廃止しているため、このままだとトレイアイコンが
表示されません。GNOME Extensions から
**"AppIndicator and KStatusNotifierItem Support"** を入れてください。
KDE Plasma はこの対応が標準で入っているので追加設定は不要です。

### オーバーレイ通知の既知の制約(正直な注意点)

- Windowsで「排他的フルスクリーン」で動くゲーム(まれに存在)には、OS側の制約で
  重ねて表示できない場合があります。多くの現代のゲームはボーダレス/フルスクリーン
  最適化で動くため、その場合は問題なく表示されます。
- Linux/Wayland(KDE)では、通常のQtの「常に最前面」フラグはコンポジタの実装に
  依存します。X11セッションなら安定して動作します。より確実にしたい場合は
  将来的に `LayerShellQt` 系のWayland layer-shellプロトコル対応を追加検討します。

## フェーズ2: 実プロトコルの組み込み

1. Wireshark + USBPcap でレシーバーの通信をキャプチャする(手順は会話内で案内済み)
2. 左右それぞれの切断/再接続時に変化するバイトを特定する
3. `hidapi` などでそのUSBデバイスを開き、該当バイトを読み取るコードを
   `device.py` の `_poll()` に実装する
4. `_set_left(False)` / `_set_right(False)` を適切なタイミングで呼ぶように書き換える

UI(トレイ・通知・ステータスウィンドウ)側は一切変更不要です。
